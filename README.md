ГИС ЕЦП Экспорт - программа для автоматизированной выгрузки запросов из информационной системы **«ГИС ЕЦП»** Социального фонда России.

ГИС ЕЦП Экспорт может использоваться в связке с программой **[ГИС ЕЦП Монитор](https://github.com/Tetrz/GIS-ECP-Monitor)**, которая предназначена для мониторинга папки с запросами, загруженными из ГИС ЕЦП, и контроля наличия файлов, подлежащих печати т.е. для более глубокой автоматизации.

## 📌 Описание

Программа автоматизирует процесс выгрузки запросов из ГИС ЕЦП, минимизируя участие пользователя.

Работа приложения основана на взаимодействии с **Яндекс Браузером** и эмуляции действий пользователя в веб-интерфейсе системы.

Поддерживаются три режима работы:

- ручной экспорт с самостоятельным входом в ГИС ЕЦП;
- ручной экспорт с автоматизироанным входом в ГИС ЕЦП с использованием электронной цифровой подписи;
- полностью автоматический экспорт по расписанию с использованием для входа в ГИС ЕЦПэлектронной цифровой подписи.

Подробнее о приложении читайте в [справочном руководстве](./Res/Help.pdf)

---

## 🚀 Возможности

- Выгрузка запросов за выбранную дату
- Автоматическое скачивание всех запросов
- Объединение загруженных PDF-документов в единый файл `Merged.pdf`
- Докачка запросов после прерывания процесса
- Автоматический вход через ЕСИА с использованием электронной цифровой подписи
- Выбор организации при наличии нескольких организаций в учётной записи
- Автоматический запуск по расписанию с помощью Планировщика заданий Windows
- Логирование работы приложения
- Быстрое открытие папки с результатами

## 🖥️ Как работает

1. Программа открывает Яндекс Браузер.
2. Выполняется вход в ГИС ЕЦП.
3. Начинается автоматическая выгрузка запросов за выбранную дату.
4. Все полученные документы сохраняются в выбранную папку.
5. После завершения создаётся объединённый файл **Merged.pdf**.

В случае прерывания процесса поддерживается **докачка** недостающих документов.

## ⚙️ Автоматический режим

Программа может работать полностью без участия пользователя.

Для этого поддерживаются:

- запуск по Планировщику заданий Windows;
- автоматический вход с использованием электронной подписи;
- автоматический ввод PIN-кода;
- автоматический выбор организации;
- автоматическое завершение работы после окончания экспорта.

## 📋 Требования

- Windows 10 / Windows 11
- .NET Framework 4.7.1 и выше
- Яндекс Браузер
- Доступ к ГИС ЕЦП

Для автоматического входа:

- КриптоПро CSP;
- Госплагин;
- расширения Госплагина и КриптоПро для Яндекс Браузера.
